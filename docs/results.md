# Study result conventions

Branch end powers are injections into the branch from each end. Real loss is their sum; net reactive consumption may be negative because charging injects var. Utilization uses the larger apparent-power magnitude of both ends. Bus required generation is calculated injection plus connected load; it is aggregate and can include slack balancing. Bus shunt loss is reported separately from branch loss. The final convergence history belongs to the last reactive active set; iterations sum across every active-set solve. All results use MW/MVAr, pu and degrees.
