# Reporting and exports

The workbench exports the native network separately from a full-precision result. Network JSON preserves topology, parameters, names and optional layout coordinates. Result JSON preserves method diagnostics and study assumptions. Print uses the browser's PDF/print renderer and includes the current network, summary, results and chart; interactive editing controls are hidden. Interactive SVG plots are presentation aids. Use the numerical record for exact values and confirm that the study converged before interpreting its profile.
